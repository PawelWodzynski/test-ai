## Zadanie 1 - Stwórz aplikację do zarządzania zadanami w Pythonie ##
Poniżej znajduje się podstawowy projekt, który można użyć jako punkt początkowy. Niniejszy plik ma odebrane kilka właściwych informacji i następujące polecenia, aby zainstalować potrzebne moduły:
```python
pip install flask Flask-SQLAlchemy pymysql  # dla bazy MySQL/MariaDB jako SQLite lub PostgreSQl. Aby używać innej, wpisz nazwę serwera i połączenie z databasem
pip install -r requirements.txt  # Instalowanie potrzebnych modułów przy pomocci pliku "requirements.txt"
```  
Następnie możesz uruchomić aplikację w trybie debuggowania, użycie SQLite lub PostgreSQl: 
```python
export FLASK_APP=app.py     # Dla Flask (wersji Python) jako środowiska pracy zabezpieczającego i współdziałującym na porcie localhost:5000
flask run                    # Uruchomieniu aplikacjii flasu. Wersja Python jest domyślnie zastosowana dla Flask, czyli najbardziej skuteczna i przeznaczone do produkcji
```  
Zadaniu w tym maksymalnie możemy ograniczyć się zakres aplikowania, którym jest potrzebny projekt i zaangażdanych plikach. Oto kilka punktów nauczania dla Was:
- Tworzenie modeli do reprezentacji bazy danych (np User, Task). Wszystkim wymagane jest ustawienie środowiska dewelopmentalnego. Ustaw zmian dotyczących pliku settings/development_settings
- Dodanie autentykacji użytkownika i innego wymaganej do aplikacji (np przez logowanie). Załóż kluczy zabezpieczeni dla poziomu API, obrótki tajne są one następnie ustawiane w plikach.
- Tworzenie środowisko do testowań (np TestingSettings). Załóż zmiennych i jakimiś konfiguracjami dla tego środowiska, a następnie ustaw ten w pliku.
- Tworzenie serwera do proponowanej rozwiązaniu oraz interfejs API zwracać bardzo podstawyczny schemat dla tego środowiska, za którym moglibśmy narzuci.
- Pamiętaj o wszelkich potrzebach statycznych (np CSS i JavaScript). Dodatkowa logika biznesowa powinna być istotnym zadaniem, a także nie musimy stosować na szablonach.
- Zawsze sprawdzi poprawność tych prób w katalogu tests jako materiał do odpowiednich testów dla proponowanego rozwiązania, a nie powinna ona być zmodyfikowana.
